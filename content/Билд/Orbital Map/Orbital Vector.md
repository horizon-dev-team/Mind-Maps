**Статус:** Базовый фундамент (Завершено)
**Тип:** `/datum/orbital_vector`
## Суть

Вся математика системы (позиции, скорости, ускорения, направления тяги) построена на структуре `/datum/orbital_vector`. В отличии списка (например, `list(x, y, z)`) датумы работают быстрее и это более читабельнее, как аналог переменной вектора если бы она была в **Byond**.

У каждого орбитального объекта есть **`position`** и **`velocity`**, отвечающие за координаты и скорость.
```dm
/datum/orbital_object
    var/datum/orbital_vector/position
    var/datum/orbital_vector/velocity
```
Таким образом вместо списков мы обращаемся (`position.Subtract(target)` вместо `position[1] - target[1]`).

## Архитектура и особенности Byond

- **Мутирующие vs Возвращающие методы:** Класс разделен на методы, которые изменяют текущий вектор (например, `AddSelf`, `ScaleSelf`, `Set`), и методы, которые возвращают новый вектор (`Add`, `Subtract`, `Scale`, `Cross`).
- **Оптимизация аллокации:** В Byond создание новых объектов (`new`) нагружает сборщик мусора (GC). В горячих циклах (например, внутри `process()` шаттла, который вызывается каждый тик) мы стараемся использовать `*Self` методы, чтобы не спамить память.
- **Очистка:** Все векторы внутри датумов (например, `thrust`, `velocity` внутри шаттла) должны быть очищены через `QDEL_NULL()` в `Destroy()`.

## Ключевые методы

**Базовые манипуляции**
- `Set(_x, _y, _z)` - Установка новых значений.
- `AddSelf(other)` - Прибавление другого вектора.
- `ScaleSelf(scalar)` - Умножение на число.

**Вычислительные (Возвращают новый вектор)**
- `Add(other)` / `Subtract(other)` - Сложение/вычитание.
- `Scale(scalar)` - Масштабирование.
- `GetNormalized()` - Возвращает единичный вектор (направление). Безопасен для нулевого вектора.

**Продвинутая геометрия (Для автопилота, физики и оружия)**
- `Dot(other)` - Скалярное произведение. Используется для вычисления проекции скорости на вектор и углов между объектами.
- `Cross(other)` - Векторное произведение. Критически важно для 3D: позволяет найти перпендикуляр (нормаль) к двум векторам. Будет использоваться в боевой системе для расчета точки упреждения и в RCS для нахождения локальных осей корабля.
- `Project(onto)` / `Reject(from)` - Проекция и отклонение. Незаменимы для разложения вектора скорости на составляющие (например, отделить скорость сближения от тангенциальной скорости при стыковке).
- `Lerp(target, t)` - Линейная интерполяция. Применяется в TGUI для сглаживания рывков (интерполяция позиции между тиками сервера).
- `AngleBetween(other)` - Угол между векторами. Нужен для секторов обстрела орудий и радаров.

## Интеграция с системами

- **[[3D Проекция на 2D Канвасе]]**: Векторы передаются в утилиту `projectPoint`, где над ними совершаются матричные преобразования (поворот камеры, перспективное масштабирование).
- **[[Модель Полета Шаттла]]**: Шаттл оперирует векторами `position`, `velocity`, `thrust`, `rcs_strafe`. Автопилот вычисляет вектор `steer` как разницу между `desired_velocity` и текущей `velocity`.
- **[[Динамика Планет]]**: Скорость планеты вычисляется аналитически через производные тригонометрических функций и записывается в вектор `velocity`.
