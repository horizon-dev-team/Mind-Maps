**Статус:** Завершено
**Тип:** Механика отказов / Боеприпасы

## Обзор
Логика осечек, заклинивания и износа оружия полностью вынесена из `/obj/item/gun` в `/datum/caliber`. Теперь калибр сам определяет, насколько он надёжен и какие последствия имеет его использование.

## Как это работает
### Шанс осечки (`misfeed_chance`)

Если патрон имеет `is_standard = FALSE`, при выстреле вызывается `check_misfeed()`:
```dm
if(chambered?.caliber?.check_misfeed())
    owner.bolt_locked = TRUE // Затвор заклинило
```

### Износ ствола (`integrity_damage`)

Нестандартные патроны наносят дополнительный урон стволу при каждом выстреле:
- `integrity_damage = 0` — стандартный патрон, без износа
- `integrity_damage = 5` — surplus патрон, ускоряет износ

### Прилипание гильз
При осечке гильза может застрять в chamber, требуя ручного извлечения или автоматической очистки при следующей перезарядке.
