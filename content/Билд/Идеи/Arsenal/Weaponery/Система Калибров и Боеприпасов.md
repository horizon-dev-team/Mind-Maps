**Статус:** Частично завершено
**Тип:** Патроны / Совместимость

##### Как было:
Ранее Калибр был просто строкой (`caliber = "10mm"`).
Проверка совместимости сводилась к пододит ли название калибра к оружию.
Осечки и износ были привязаны к конкретным баллистическим пушкам.
Более одного калибра мог использовать только револьвер детектива.

##### Как стало:
Теперь Калибр - это информация (`/datum/caliber`).
Магазины и патроны хранят ссылку на датум своего калибра, пример: `var/datum/caliber/caliber = /datum/caliber/c9mm`
Логика совместимости и осечек полностью изолирована в датуме.

**Пример реализации:**
```dm

/datum/caliber/c9mm_surplus
    name = "9mm Surplus"
    caliber_type = "9mm" // Физически влезет в любой магазин 9мм
    is_standard = FALSE // Но нестандартный
    misfeed_chance = 15 // 15% шанс заклинить пушку
    misfire_increment = 2
    integrity_damage = 5 // Портит ствол быстрее

// Проверка при попытке вставить патрон в магазин:
/datum/caliber/proc/can_fit(datum/caliber/other_caliber)
    return caliber_type == other_caliber.caliber_type

// Проверка при выстреле (в /datum/feed_system/ballistic):
    if(chambered?.caliber?.check_misfeed())
        owner.bolt_locked = TRUE // Заклинило затвор
```

**Совместимое оружие:** Любое оружие, использующее `accepted_magazine_type` или внутренние магазины.
Если патроны одного `caliber_type`, они будут заряжаться. Если `is_standard == FALSE`, пушка может заклинить.
